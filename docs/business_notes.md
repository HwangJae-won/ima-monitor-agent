# IMA 사업 공부 노트

프로젝트를 시작하기 전에 답하려고 한 다섯 질문과, 공개 자료에서 찾은 답입니다.
`[확인 필요]` 표시는 기사 검색 결과로만 본 것이라 원문(금융위 보도자료, 회사 공시·상품설명서)으로 재확인해야 하는 항목입니다.
지원서·면접에서 수치를 말할 때는 반드시 기준 시점과 출처를 함께 말합니다.

## 1. 한국투자증권은 왜 IMA 사업을 확대하는가

- 2026년 신년사 'Beyond Boundaries' — 자본·국경·업의 경계를 넘는다는 메시지. 자본의 경계에서 IMA 를 "신규 수익원이자 대한민국 성장 동력의 일익"으로 언급하고, "IMA 사업에서 무엇보다 중요한 것은 철저한 리스크 관리"라고 강조. (딜사이트·인더뉴스 2026.01.02 보도) `[원문 확인]`
- 2025년 11월 금융당국이 한국투자증권과 미래에셋증권을 국내 첫 IMA 사업자로 지정. `[확인 필요]`
- 자기자본 한도 안에서만 할 수 있던 기업금융을 고객 수탁금으로 넓힐 수 있다는 점이 사업 확대의 동기로 보인다. (추론)
- 2026년 1월 1일 조직개편에서 종합금융본부와 IMA 담당을 묶은 그룹을 신설했다는 보도. `[확인 필요: 조직명·담당 범위]`

## 2. 조달한 자금을 어디에 투자해 어떻게 수익을 만드는가

- 제도 요건: 기업금융 관련 자산 70% 이상, 만기 1년 이상 자산 비중, 부동산 한도, 모험자본 의무 비율(2026년 10% → 2028년 25%), 손실충당금. `[확인 필요: 금융위 IMA 제도 자료 원문의 정확한 비율·시행 일정]`
- 1호 상품(2025.12): 2년 만기 폐쇄형, 기준수익률 연 4.0%(목표이지 확정 수익률이 아님), 초과수익의 일부를 성과보수로. 4영업일 만에 약 1조 원 모집. 3개월 시점 운용현황에서 대출·펀드 비중이 높았다는 보도. `[확인 필요: 상품설명서·운용보고서]`
- 2호는 목표액에 못 미쳤다는 보도 → 과제가 "모으기"에서 "어디에 투자하고 어떻게 회수하나"로 옮겨감. `[확인 필요]`
- 외부 우려: 단기 조달(발행어음) 대비 장기 자산의 만기 불일치, 외형 확대에도 운용손익 감소, 부동산 익스포저. (신용평가사·언론) `[확인 필요]`

## 3. 투자 전 심사와 투자 후 모니터링은 어떻게 다른가

| | 투자 전 심사 | 투자 후 모니터링 (이 프로젝트) |
|---|---|---|
| 질문 | 이 기업에 자금을 공급해도 되는가 | 투자 시점과 비교해 상태가 달라졌는가 |
| 핵심 자료 | 사업성, 상환능력, 담보·보증, 약정 조건 | 재무·공시의 **변화**, 약정 준수, 자금조달 이행 |
| 결과 | 승인/조건부/거절 | 관찰 유지 / 추가 확인 / 검토 요청 |
| 공개 자료로 가능한 부분 | 재무·공시 기반 분석까지 | 재무·공시·시장 반응의 변화 감지까지 |
| 내부 자료가 필요한 부분 | 담보 가치, 약정 조건, 비공개 사업 정보 | 상환 지연, 약정 위반, 담보 재평가 |

조직별로 어느 부서가 사후관리를 맡는지는 외부에서 확인할 수 없어, 프로젝트에서는 "기업금융 투자자산 모니터링 담당자"를 가정했다.

## 4. 주가 하락과 상환능력 악화는 어떻게 구별하는가

| 관측 상황 | 검토할 질문 |
|---|---|
| 주가는 크게 하락, 영업현금흐름·현금성자산은 유지 | 시장 전체 하락인가? 기업의 상환능력에도 변화가 있는가? |
| 주가는 안정, 단기차입금 증가·현금흐름 악화 | 가까운 만기의 차입금을 감당할 자금이 있는가? 차환 계획이 공시됐는가? |
| 주가 하락과 현금흐름 악화 동시 발생 | 공시에서 자금조달·차환·사업 악화 근거를 추가 확인할 수 있는가? |

→ `monitor/signals.py` 가 상환능력 신호와 시장 신호를 분리해 내고, Agent 의 종합 검토가 두 신호의 관계(일치/엇갈림/부족)를 적는 이유.

## 5. 공개 데이터로 확인할 수 있는 위험과 내부 정보가 필요한 위험

| 공개 자료로 가능 | 내부 자료가 필요 |
|---|---|
| 정기보고서 재무 변화 (분기 지연 있음) | 상환 지연·연체 |
| 자금조달 결정·완료 공시 | 약정(covenant) 준수 여부 |
| 신용사건 공시 (회생·부도·채권은행 관리) | 담보 가치 재평가 |
| 시장 반응 (주가·수급·공매도·신용잔고) | 경영진 면담, 비공개 사업 계획 |
| 감사의견, 소송, 최대주주 변경 | 실제 편입 조건(금리·만기·순위) |

→ 메모의 "추가 확인 사항"은 오른쪽 열을 가리키도록 설계했다.

- 2026.01.01 조직개편의 정확한 조직명과 역할
- 신용평가사 보고서의 우려 표현 원문
