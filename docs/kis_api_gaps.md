# KIS Open API 확장 가능 영역 메모 (자소서·면접용)

KIS Developers 의 API 그룹(2026.10 기준 20개: 국내·해외 주식/선물옵션/채권의 시세·주문·계좌, 실시간, OAuth, 제휴사)을
공식 샘플 저장소(334개)·경쟁사 API·제도 변화와 대조해 "아직 없는 것"을 정리한 것이다.
**사실(없다는 것)과 의견(나올 것 같다는 것)을 구분해서 말할 것.** 한투 내부 로드맵은 확인된 바 없다.

## 1. 지금 API 에 없는 데이터 영역 (사실)

| 없는 것 | 비고 |
|---|---|
| 발행어음·IMA·RP 잔고·수익률 조회 | 한투 핵심 상품인데 API 로는 못 봄. 토스뱅크 앱에서는 발행어음을 24시간 판매 |
| 연금계좌 확장 | 현재 5종(잔고·입출금 수준). 디폴트옵션·상품 매매·실물이전 관련 없음. 2026년 연금 MTS 를 거의 매달 개편, 'AI 투자비서' 시연(10.6) |
| ETF 괴리율·추적오차 | 구성종목·NAV 는 있으나 괴리율 필드 없음 → 직접 계산 |
| 뉴스·공시 본문 | 제목만 제공. MCP·LLM 연동을 밀면서 본문이 없음 |
| 리서치 리포트·AI 시황 API | '지금 시장은', '들려주는 리서치', 글로벌 독점 리서치가 앱 안에만 있음 |
| 상장폐지·관리종목 이력 | 현재 상태 플래그만. 2026.7 코스닥 상폐 요건 강화로 수요 증가 |
| 종목 마스터의 API 화 | .mst 파일을 내려받아 파싱해야 함 |

## 2. 경쟁사가 먼저 낸 것 (사실, 2026.10 기준 보도)

| 기능 | 어디 | 한투 |
|---|---|---|
| 조건부·복합 주문 (OCO, 트레일링, 조건 충족 시 주문) | 토스증권 Open API (2026.8) | 단순 예약주문 |
| 고객용 자연어 주문 → 미리보기·승인 | 다올 'MCP 트레이딩' (2026.10) | 한투 MCP 는 개발자용, 확인 훅은 kis-ai-extensions |
| 해외주식 공시·어닝콜 데이터 | 신한(AI 공시 요약), 카카오페이(어닝콜 번역) | 없음 |
| 국내·해외 통합 단일 연동 | 토스, NH PLUG | 국내·해외 TR 분리 |

## 3. 제도 변화로 필요해질 것 (의견)

- NXT·KRX 애프터마켓 전용 시세: 현재 `J/NX/UN` 시장구분으로 대응하지만 프리·애프터마켓 OHLC, KRX 애프터마켓(2026.9.14~) TR 매핑이 불명확. 최선집행 관련(어느 시장 체결) 조회 가능성
- 토큰증권(2027.2 시행): 발행·유통 조회 그룹 신설 가능성. 한투 독자 플랫폼 RFP, 카카오 MOU
- 공매도 재개(2025.3) 관련: 대차·공매도는 있으나 KRX 잔고 공시와 연계 없음

## 4. 한투 디지털 방향에서 예상되는 것 (의견)

- Trading MCP 도구 확장: 현재 166개 API 만. 웹소켓·예탁원정보·재무·공매도 상위 빠짐 → 샘플 334개 전부 노출이 1차 과제일 듯
- API 상태·장애 공지·호출 유량 조회 엔드포인트: 2026 전산장애 배상 업계 1위, 책무구조도가 IT 장애를 겨냥 → 개발자용 상태 API 는 비용 대비 효과 큼
- 공식 저장소 Issues 탭 개방 (현재 비활성, PR 만 가능)

## 5. 이 프로젝트에서 실제로 아쉬웠던 것 (사실·경험)

- 기업금융 사후관리에는 시세보다 **채권·신용 데이터와 공시 연계**가 필요했다
  - 장내채권 그룹에 발행정보는 있으나 신용등급·만기 구조가 얇음
  - 재무제표 주석(차입금 만기·약정)·공시 본문은 DART 영역이라 KIS 로는 불가
  - 상장폐지·관리종목 이력 없음
- 교차검증에 쓴 KIS `finance_*` 는 결산년월 기준이라 '공시 시점' 기준 필터가 안 됨 (DART 접수일로 대체)
- 샘플 저장소 결함 1건 발견: `etfetn/inquire_component_stock_price/chk_*.py` COLUMN_MAPPING 이 신용잔고 API 라벨로 오염 (`/home/user/kis_api_bug_notes.md`)

## 자소서·면접 문장 후보

> KIS API 를 실제 업무 흐름(기업금융 사후 모니터링)에 써 보니, 시세·주문은 충실한데 기업금융 쪽 데이터 — 채권 신용등급·만기 구조, 상장폐지 이력, 공시 본문 — 는 외부 소스로 보완해야 했습니다. 입사하면 사용자이자 기여자로서 개발자 생태계의 데이터 그룹 확장을 제안하고 싶습니다. (사용 중 발견한 샘플 코드 결함은 PR 로 제출했습니다.)
